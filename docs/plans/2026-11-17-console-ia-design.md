# 控制台信息架构（方案 A）

> 2026-11-17 · 已确认，按此实施  
> 只改界面布局与文案，不改接口、不新增能力。

## 目标

日常操作集中在「终端」工作台：先勾选机器，再就地下命令。观察 / 协助是这张表上的会话舞台。剪贴板和一对一传文件只在协助模式出现。批量收集 / 下发使用当前勾选。`/remote` 转入终端。

## 导航

运维：工作台、终端、镜像库、边缘节点、维护任务。  
配置：校区 / 机房、PE 会话、管理员、外观主题。  
顶栏保留用户、主题、退出。

## 列表骨架

页头（标题 + 一行计数）、上下文条（机房记在本机 `idv.lab`）、命令条（危险操作靠右）、紧凑表 + 右侧抽屉。  
校区 / 机房仍是结构配置页。工作台是可点进终端和任务的状态板。

## 终端

扫读列：状态（圆点 + 文字）、名称、上报 IP、MAC、机房、还原、Agent、最近心跳。  
分配 IP、备注、编辑在抽屉。分配 IP 与上报 IP 不一致时，IP 列有标记。  
命令随勾选数量启用：0 台为登记；1 台增加观察、协助、采集；多台可电源、部署、移动、收集、下发、删除。更新 Agent 在「更多」，跳到维护任务并带上已选 MAC。  
恰好一台在线时，「协助」为主按钮。部署按钮与弹窗都写「部署」（原「清除缓存」只是文案）。

## 会话舞台

打开后占据主区域，结束回到原筛选。协助模式右侧为「剪贴板 | 文件」。观察模式没有该栏。底部窄名单换机：结束当前会话，再按同一模式发起。批量文件不在舞台里，结果仍进维护任务，舞台只留「查看任务」。

## 不做

不改会话种类、剪贴板权限、文件任务接口、主题令牌。不加锐起有而本系统没有的列或按钮。
