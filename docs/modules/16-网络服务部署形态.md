# 模块 16 — 网络服务部署形态（Center 管配置 / Edge 可同机）

> 版本：v0.1 · 2026-11-12  
> 结论：DHCP/PXE **配置只在中心**；**进程属 Edge 角色**，可与 Center 同机或独立主机。

---

## 1. 结论摘要

- 中心是唯一管理入口：网段授权、DHCP 模式（full/proxy/off）、PXE 菜单与默认任务。  
- Edge 负责执行网络服务与镜像缓存；学校服务器少时，允许 **同机多进程**。  
- 镜像大流量优先走缓存节点，避免单台中心成为瓶颈。

---

## 2. 三种装法

| 形态 | 进程布局 | 何时用 |
|------|----------|--------|
| 单机 | 一台主机：`idv-center` + `idv-edge` | 试点、机房少、预算紧 |
| 中心 + 边缘 | Center 独立；每机房/楼栋一台 Edge | 500+、多校区 |
| 混合 | 部分网段用中心同机 Edge，部分用独立 Edge | 逐步扩容 |

管理端统一展示「网络服务 / 缓存节点」，不向网管强推必须买多台服务器。

---

## 3. 职责边界

| 能力 | Center | Edge |
|------|--------|------|
| 台账 / 任务 / 审计 | ✅ | 上报 |
| DHCP/PXE **配置** | ✅ 编辑与下发 | 拉取并应用 |
| DHCP/PXE **进程** | ❌（不内嵌） | ✅ 可开可关 |
| 镜像元数据 | ✅ | 副本状态 |
| 镜像字节流 | 可选源站 | ✅ 就近缓存 |
