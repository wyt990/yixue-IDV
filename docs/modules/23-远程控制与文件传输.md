# 模块 23 — 远程控制（观察 / 协助）与文件传输

> 在「远程控制」页面对单台终端发起会话：
> - **观察模式**：只接收屏幕画面，不能操作；
> - **协助模式**：屏幕 + 键鼠控制 + 文本剪贴板共享 + 文件互传；
>
> 另支持按机房/勾选多台终端做 **文件收集 / 文件下发**（可指定目录）。

---

## 1. 架构

```text
浏览器（远程控制页）
   │ 轮询屏幕帧 / 发送输入、剪贴板、文件请求
   ▼
Center（中继）
   ├─ 内存保存每个会话最新 JPEG 帧
   ├─ assist_commands 队列（input/clipboard/fs）
   └─ assist_file_requests + data/assist-fs 临时文件
   ▲
   │ 用户会话中的 idv-agent assist-helper
   │（屏幕捕获、键鼠注入、剪贴板、文件上传/下载）
   ▼
登录中的 Windows 桌面
```

**为什么需要 helper**：`idv-agent` 服务运行在 Session 0，不能截屏、也不能把键鼠注入
用户桌面。服务收到 `assist_start` 后，通过 `CreateProcessAsUser`（WTS 当前用户令牌）
在登录会话中启动 `idv-agent assist-helper`；helper 自己长轮询 Center 的会话命令。

---

## 2. 观察模式

- 服务端：创建 assist 会话（`kind=view`）→ 入队 `assist_start`；
- helper：PowerShell + `System.Drawing.CopyFromScreen` 抓屏，缩放到最大宽 1280，
  JPEG 质量 60，约 1~2 帧/秒上传到 Center；
- 浏览器：每 350ms 拉取 `/api/v1/assist/sessions/{id}/frame` 显示；
- 观察模式下发输入会被 Center 拒绝（403）。

## 3. 协助模式

- 创建会话时 `kind=control`；
- 浏览器画布发送鼠标移动/按下/抬起/滚轮、键盘按键、文本；
- Center 入队 `assist_commands(kind=input)`，helper 长轮询后调用 Win32
  `SetCursorPos` / `mouse_event` / `keybd_event`；
- 文本输入通过“剪贴板 + Ctrl+V”处理中文/特殊字符；
- **剪贴板**：文本双向同步（读取客户端/发送到客户端）；
- 所有输入仅 control 模式生效。

## 4. 文件传输

### 4.1 一对一（资源管理器式）

- 浏览器列表请求 → `assist_file_requests(kind=list)` → helper 返回目录项；
- 下载：helper 读取客户端文件并上传到 Center 临时文件，浏览器下载；
- 上传：浏览器上传到 Center，helper 下载并写入客户端指定路径；
- 当前为**串行请求**（文件列表/单个文件），大文件受 512MB 上限约束。

### 4.2 一对多（批量）

| 操作 | 参数 | 流程 |
|------|------|------|
| 收集 | 目标 MAC + 源目录 | helper 用 `ZipFile.CreateFromDirectory` 打包 → 上传 Center；Center 保存 `<task>/<mac>.zip` |
| 下发 | 目标 MAC + 目标目录 + zip | Center 保存 bundle.zip → helper 下载并 `Expand-Archive` 到目标目录 |

- 复用 `maintenance_tasks` 表（kind=`file_collect` / `file_distribute`），
  任务列表/进度/取消/导出沿用维护任务；
- 收集结果可在远程控制页「最近文件任务」下载对应客户端 zip；
- 一次任务可勾选多台终端，目标目录由管理员填写。

## 5. 接口摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/assist/sessions` | 创建会话 `{mac,kind:view/control}` |
| GET | `/api/v1/assist/sessions/{id}/frame` | 最新 JPEG 帧 |
| PUT | `/api/v1/assist/sessions/{id}/frame` | helper 上传帧（无登录鉴权，随机 session id） |
| GET | `/api/v1/assist/sessions/{id}/commands/next?wait=10` | helper 长轮询 |
| POST | `/api/v1/assist/sessions/{id}/input` | 浏览器发键鼠事件（仅 control） |
| GET/POST | `/api/v1/assist/sessions/{id}/clipboard` | 读/写剪贴板 |
| POST | `/api/v1/assist/sessions/{id}/fs/list|download|upload` | 一对一文件 |
| POST | `/api/v1/tasks/file-collect` | 批量收集 |
| POST | `/api/v1/tasks/file-distribute?target_dir&macs` | 批量下发（raw zip） |
| GET | `/api/v1/file-tasks/{task}/{mac}/archive` | 下载收集结果 |
| PUT | `/api/v1/file-tasks/{task}/{mac}/collect` | helper 上传收集 zip |
| PUT | `/api/v1/file-tasks/{task}/{mac}/result` | helper 上报下发结果 |

## 6. 使用步骤

1. Center 重启（迁移 `021_remote_control.sql`）；
2. 客户端安装 **0.3.2+** Agent（含 `assist-helper`），服务/计划任务正常运行；
3. 管理员登录 → 左侧「远程控制」；
4. 选择客户端 + 观察/协助 → 发起会话；
5. 屏幕出现后可：
   - 协助模式下直接键鼠操作；
   - 剪贴板读取/发送；
   - 文件路径浏览、上传/下载；
   - 下方勾选客户端做批量收集/下发。

---

## 7. 限制与注意

- 屏幕是 **HTTP 轮询 JPEG 帧**（约 1~2 fps），不是 WebRTC；局域网可用，公网/弱网延迟明显；
- 需客户端**有已登录的交互式用户会话**，锁屏/UAC 安全桌面可能抓到黑屏；
- 键鼠注入要求 helper 运行在当前用户桌面，服务方式启动是必须的；
- 剪贴板仅文本；大文件串行传输，不压缩不续传；
- helper 接口按随机 session id 识别（无设备令牌），仅适合受控机房网络；
- 观察/协助会显著增加带宽与 CPU，建议一次只对少量终端发起。
