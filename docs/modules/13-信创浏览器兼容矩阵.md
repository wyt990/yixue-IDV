# 模块 13 — 信创浏览器兼容矩阵（管理端）

> 对应总纲阶段 6 / 模块 01。目标：学校常见国产化与 Chromium 内核浏览器可完成日常网管操作。

---

## 1. 基线声明

- 管理端为 **Vite + React SPA**，依赖现代 CSS 变量与 ES2020 级语法（由构建工具降级打包）。  
- **推荐内核**：Chromium ≥ 90（含多数信创浏览器壳）。  
- **不承诺**：IE11、极旧 WebKit、无 ES Module 的内置浏览器。

## 3. 前端兜底约定

- 字体栈含 `Noto Sans SC` / `Source Han Sans SC`，避免仅 Inter。  
- 主题靠 `data-theme` + CSS 变量，不依赖 CSS Nesting / `:has()` 做关键布局。  
- 本地记住主题键 `idv_theme`。  
- 外观页展示本矩阵入口说明。
