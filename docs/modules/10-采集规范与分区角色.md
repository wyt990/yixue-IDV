# 模块 10 — 采集规范与分区角色（一期）

> 目标：金样机采集时约定分区角色，便于阶段 4 入库与二期还原；本阶段以文档 + 镜像 meta 约束为主。

---

## 1. 镜像格式 `yixue-image-v1`

磁盘采集产物为自描述包：

```text
MAGIC "YIXUE1\n"
u32le header_len
JSON ImageHeader
payload bytes（块级磁盘/分区拼接内容）
```

`ImageHeader` 关键字段：

| 字段 | 说明 |
|------|------|
| `format_version` | 当前为 `1` |
| `os_family` | `windows` / `linux` / `other` |
| `boot_mode` | 如 `uefi` / `legacy` |
| `partitions[]` | 分区角色表（见下） |
| `payload_sha256` | 载荷 SHA-256 |
| `payload_size` | 载荷字节数 |

中心 `images.partition_map` 保存与 header 中 `partitions` 相同的 JSON，供部署预览与二期还原使用。

---

## 2. 分区角色约定

| role | 含义 | 一期部署 | 二期还原预期 |
|------|------|----------|--------------|
| `system` | 系统区（OS + 程序） | 部署默认覆盖 | 开机还原目标 |
| `persistent` | 持久数据（作业、课堂资料） | `wipe_whole_disk` 会覆盖；`wipe_target_partitions` / `write_system_only` **保留** | 还原时保留 |
| `volatile` | 临时区（可选） | 同 persistent 策略 | 可清空 |

### 金样机建议布局（封板前）

1. 至少两区：系统区 + 数据区（不必与 Windows C/D 字母一一对应，以 role 为准）。  
2. 关闭休眠/快速启动；清理个人文件与本机唯一标识策略按机房规范执行。  
3. 采集前确认数据区无敏感考试卷库以外的垃圾数据。  
4. 默认采集工具按容量比例切分：约 2/3 `system`，剩余 `persistent`（可用真实分区表替换，二期增强）。

---

## 3. 采集流程（阶段 4）

1. 管理端创建 **capture** 任务（指定 MAC）。  
2. 金样机 PXE/PE 报到 Edge → 领取任务。  
3. `pe-agent capture` 读取磁盘（试点可用 `--disk-file` 模拟）→ 打包 → 经 Edge `ingest` 入库。  
4. Center 生成 Image 记录（含 checksum、partition_map）。  
5. 按需 **同步到边缘**，再对学生机下发 **deploy**。

---

## 4. 部署与失败语义

- 部署策略见 [02-镜像部署与磁盘处理](./02-镜像部署与磁盘处理.md)。  
- 校验失败：**不得**报成功；写入 `.deploy-failed` 标记，任务 `failed`，可重试。  
- 半写入磁盘可能无法启动——属预期风险，需重部署。

## 5. 排除大文件 / 临时目录

采集编码为 `ntfs_used_v1`（按已用簇）。排除靠**打包时解析 MFT 跳过簇**（不改金样盘、也不依赖 PE 里的 ntfs-3g）：

| 能力 | 说明 |
|------|------|
| 打包跳过 | 解析 NTFS，从 used-bitmap 清掉 pagefile / hiberfil / Temp 等路径的簇（任务可关） |
| 挂载清除 | PE 若有 ntfs-3g 可顺带删文件（best-effort；Alpine 默认 modloop 无 fuse 时常失败） |
| 日志 | stderr / 任务 detail 带 `[exclude] pack-skip …` |

默认排除：`pagefile.sys`、`swapfile.sys`、`hiberfil.sys`、`$Recycle.Bin`、`Windows\Temp`、`Windows\Prefetch`、用户 `Temp` 等。

> 若排除前后镜像几乎一样大，多半是旧 pe-agent 只做了挂载清除且挂载失败；请确认 Edge 提供的 `pe/linux/idv-pe-agent` 已含 pack-skip。

效率演进（见 [①②设计](../plans/2026-11-12-image-efficiency-12-design.md) / [排除+流式差量](../plans/2026-11-13-exclude-and-streaming-delta-design.md)）：
- **① NTFS 跳空闲**：`encoding=ntfs_used_v1`
- **② 边传边校验** + 同机入库
- **流式差量**：两版 full → delta → apply 出新 full；部署仍用新全量
- **③ CDC**：后续
