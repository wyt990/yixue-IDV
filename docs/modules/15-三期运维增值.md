# 模块 15 — 三期运维增值（阶段 7）

> 远程协助信令、软件分发、多角色、上课只读、定时电源、审计导出。

---

## 1. 能力摘要

| 能力 | API / 命令 | 说明 |
|------|------------|------|
| 多角色 | `admins.role` = super / lab_admin / readonly | readonly 禁写 |
| 终端标签 | `POST /api/v1/clients/{id}/tags` | `?tag=` 筛选 |
| 软件分发 | `/api/v1/software/*` + `idv-agent soft-apply` | 下载+模拟安装 |
| 远程协助 | `/api/v1/assist/sessions` + `assist-ack` | 会话状态机，非真桌面流 |
| 上课只读 | `/api/v1/ops/class-lock` | 锁定期拒部署 |
| 定时电源 | `/api/v1/ops/power-schedules` | 到点入队 WOL/关机 |
| 审计导出 | `/api/v1/audit/export.csv` | CSV |
