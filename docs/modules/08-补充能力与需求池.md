# 模块 08 — 补充能力与需求池

> 在你已提的 1～7 之外，机房 IDV/镜像体系通常还应规划的内容。

---

## 1. 建议纳入规划的能力

| 能力 | 为什么需要 | 建议分期 |
|------|------------|----------|
| **硬件型号池 / 驱动注入** | 同一镜像在不同主板/网卡上启动失败常见 | 二期 |
| **UEFI / Legacy / Secure Boot 策略** | 开机链与签名差异 | 一期 meta 记录；二期策略 |
| **唤醒与电源**（WOL、定时开关机、上课时段） | 锐起类标配运维 | 二期 |
| **远程协助 / 同屏**（只读或控制） | 教师巡堂；注意隐私与考试合规 | 三期 |
| **软件分发（非整镜像）** | 小补丁不必整盘；可与增量协同 | 二期～三期 |
| **许可证与激活提醒** | Windows 批量激活别踩坑（技术外流程） | 运维文档一期 |
| **审计与导出** | 教育局/学校检查：谁对哪台写过盘 | 一期基础，二期报表 |
| **备份与灾备** | Center 数据库 + 镜像库备份 | 阶段 5 |
| **多管理员角色** | 校级网管 / 机房员 / 只读巡查 | 二期 |
| **任务窗口与并发限流** | 防止打满交换机 | 阶段 5 |
| **终端分组标签** | 考试机、教师机、无人值守 | 一期标签，二期策略绑定 |
| **采集前「封板检查清单」** | 关休眠、清个人文件、统一计算机名策略 | 一期运维文档 |
| **失败机隔离名单** | 反复失败不要拖垮整班任务 | 阶段 4～5 |
| **日志一键打包** | 现场排障 | 阶段 4 |
| **国产化浏览器与信创管理端适配** | 学校终端多样性 | 二期 UI 验收矩阵 |
| **大镜像传输校验与损坏自愈** | 与缓存清空、P2P 校验联动 | 阶段 5 |
| **上课时段「只读配置」** | 防止误点部署 | 二期 |
| **中心统管 DHCP/PXE 配置** | 配置只在中心；Edge 同机或分离执行（见模块 16） | 一期补齐管理面；进程能力已有 |

---

## 2. 明确不优先（避免范围爆炸）

- 完整自研 Hypervisor 桌面（狭义全功能 IDV 虚拟化底座）  
- 替换学校现有 AD/域控（可对接，不重做）  
- 跨互联网公网裸奔分发镜像（无专线/VPN 设计前不做）  
- 对学生手机 App 管控
