# 模块 01 — 管理端 UI 与设计系统

> 产品：易学 IDV 机房管理系统  
> 版本：v0.1 · 2026-11-12  
> 诉求：美观、多主题、响应式；管理端要「好看且好用」

---

## 1. 结论摘要

- 管理端采用 **「壳 + 页面 + 设计令牌（Design Tokens）」** 架构，主题可切换，不写死单套配色。  
- **一期**：先有清晰信息架构与可用页面（台账/镜像/任务/节点）；视觉按本设计系统落地，避免「临时丑页面再推翻」。  
- **多主题**：至少 3 套正式主题 + 1 套深色值班主题，运行时切换，本地记住偏好。  
- **响应式**：桌面优先（网管主场景），平板可用，手机可查进度/告警（不做重度编辑）。

---

## 2. 信息架构（IA）

```text
登录
 └─ 工作台（总览：在线 edge、进行中任务、失败告警）
     ├─ 组织资产
     │    ├─ 校区 / 机房
     │    ├─ 终端（MAC、归属、最近在线）
     │    └─ 边缘节点 Edge（网络服务 + 缓存；可与中心同机）
     ├─ 镜像中心
     │    ├─ 镜像库
     │    ├─ 副本状态（各 edge 缓存）
     │    └─ 缓存清理 / 重新同步（见模块 03）
     ├─ 网络服务（后续）
     │    └─ 节点 DHCP/PXE 配置（模式、授权网段、启动菜单）
     ├─ 任务中心
     │    ├─ 部署 / 采集 / 同步
     │    └─ 任务详情与日志
     ├─ 策略（二期）
     │    ├─ 还原模式
     │    ├─ 办公 / 教学 / 考试模式
     │    └─ 网络策略（有线/WiFi 模板）
     └─ 系统
          ├─ 管理员与角色
          ├─ 外观主题
          ├─ 审计日志
          └─ 关于 / 版本
```

### 导航原则

- 左侧主导航 + 顶栏（机房快速切换、主题、当前用户）。  
- 列表页：筛选 / 搜索 / 批量操作；详情用右侧抽屉或独立页（宽表用独立页）。  
- 危险操作（部署写盘、清空缓存、删除镜像）必须二次确认，并显示影响范围。

## 3. 页面与元素清单

| 页面 | 关键元素 | 说明 |
|------|----------|------|
| 登录 | 品牌名「易学 IDV」、账号密码、主题预览小点 | 品牌要一眼可辨，避免通用后台脸 |
| 工作台 | 状态卡片、进行中任务条、失败列表、机房健康 | 一屏看清「现在能不能上课」 |
| 机房/终端 | 表格、标签（在线/离线/维护中）、批量导入 MAC | 支持 CSV 导入 |
| Edge | 卡片或表：在线、缓存占用、同步进度环形条 | 缓存容量可视化 |
| 镜像库 | 封面/系统族图标、大小、校验、适用机房标签 | Windows/Linux/信创分色标签 |
| 任务 | 时间线进度、百分比、速率、来源（Edge/P2P） | 失败可展开错误原因 |
| 主题设置 | 主题卡片预览、圆角密度、字号档 | 即时预览 |

### 通用组件

- Button / Button 危险态、Input、Select、Checkbox、Switch  
- Table（排序、分页、空状态插画区用简洁几何，不用 emoji）  
- Dialog / Drawer、Toast、Banner 告警  
- Progress（线性 + 环形）、Steps（采集/同步/部署向导）  
- Empty、Skeleton 加载骨架

## 4. 视觉方向（反「AI 默认脸」）

**不要**：紫白渐变万能后台、泛滥圆角胶囊、霓虹发光、无意义插画堆砌。  
**要**：教育机房运维气质——清晰、冷静、品牌可记、数据可读。

### 品牌信号

- 产品名「易学 IDV」在登录页与侧栏顶部为 **主识别**，字重与字号高于普通导航。  
- 可选图形：简洁「书页 + 节点」线标（单色），避免卡通。

### 主题包（一期至少实现 Token 可切换；视觉可先 2 套做满，其余补齐）

| 主题 ID | 名称 | 气质 | 主色方向 |
|---------|------|------|----------|
| `ink-lab` | 墨蓝教研 | 默认推荐；日间网管 | 深墨蓝 `#1B3A4B` + 亮青信息色 `#2A9D8F` + 纸白底 |
| `pine-rack` | 青松机柜 | 更「机房/网络」 | 松绿 `#1F6F5B` + 石墨灰结构线 |
| `slate-ops` | 暖石运维 | 偏文档/报表阅读 | 石板灰 `#3D4A54` + 琥珀强调 `#C9842A`（非整页奶油底） |
| `night-duty` | 暗夜值班 | 深色；夜间盯任务 | 炭底 `#12161C` + 月白字 + 青信息色 |

每套主题通过 CSS 变量（Design Tokens）切换，组件不写死色值。

### 字体

- 中文：`「思源黑体 / Noto Sans SC」` 或 `「阿里巴巴普惠体」`（需确认许可后打包或 CDN）。  
- 数字/日志：`IBM Plex Mono` 或 `JetBrains Mono`（进度、MAC、IP）。  
- **禁止**默认堆 Inter/Roboto/Arial 作为唯一品牌字体（系统回退链可保留）。

### 布局与响应式

| 断点 | 宽度 | 行为 |
|------|------|------|
| `xl` | ≥1280 | 侧栏固定展开 |
| `lg` | ≥1024 | 侧栏可收起为图标 |
| `md` | ≥768 | 侧栏变抽屉；表格横向滚动或关键列优先 |
| `sm` | \<768 | 工作台 + 任务进度只读；复杂表单引导「请用电脑」 |

间距采用 4/8 网格；内容区最大宽度约 1440～1600，大屏不拉成细长条。

### 动效（克制）

- 主题切换：150～250ms 颜色过渡。  
- 任务进度：数值与条平滑更新。  
- 路由切换：轻微淡入，不做花哨整页视差。  
- 尊重 `prefers-reduced-motion`。

### 无障碍

- 正文对比度 ≥ 4.5:1；焦点环可见；图标按钮有 `aria-label`。  
- 危险按钮不只靠颜色，需文案「清空缓存」「部署写盘」。

## 5. 前端技术建议

| 项 | 建议 | 说明 |
|----|------|------|
| 框架 | **React 19** + TS（推荐）或 **Vue 3.5** + TS | 版本跟模块 09；禁止 Vue2/React17 脚手架；仓库 `web/` |
| 构建 | **Vite 当前大版本（基线 8.x）** | 与模块 09 一致 |
| 样式 | CSS Variables + 轻量工具（如 Tailwind 仅作间距，主题靠 Token） | 多主题核心是 Token，不是多套页面 |
| 图表 | 任务吞吐、缓存占用用简洁图 | 避免仪表盘堆满无用图 |
| 与后端 | 同域或 CORS + Bearer；OpenAPI 生成客户端可选 | |

一期可「功能页齐全 + `ink-lab`/`night-duty` 两套主题做满」；其余主题按 Token 扩展。
