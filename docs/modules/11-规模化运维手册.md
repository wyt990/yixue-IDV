# 模块 11 — 规模化运维手册（阶段 5）

> 面向 500+ 终端、多 Edge 机房的日常运维：隔离、并发、备份、扩容与令牌轮换。

---

## 1. 多 Edge / 多机房与网段隔离

| 原则 | 做法 |
|------|------|
| 配置在中心 | DHCP/PXE 开关、模式、授权网段在 Center 管理；Edge 拉取执行 |
| 进程可同机 | 服务器少时可 Center+Edge 同机不同进程；多机房再拆独立 Edge |
| 一网段一网络服务 | 学生机只 PXE/拉镜像到本网段绑定节点，不跨核心直连 Center 大文件 |
| 管理面与数据面分离 | Center API/管理端走管理 VLAN；镜像同步走机房汇聚 |
| 跨机房 | 只同步 Center↔Edge；**禁止**默认跨机房 P2P |
| 令牌 | 每 Edge 独立 `node_token`；失陷后管理端「轮换令牌」并更新 `edge.toml` |

推荐地址规划示例：

```text
# 多机形态
机房 A：10.10.1.0/24  Edge=10.10.1.2  DHCP/PXE 由该 Edge 提供（配置来自 Center）
机房 B：10.10.2.0/24  Edge=10.10.2.2
管理网：10.20.0.0/24  Center=10.20.0.10

# 单机形态（同机不同进程）
管理+机房网：10.10.1.0/24  Host=10.10.1.2  跑 idv-center + idv-edge
```

## 2. 「100 台同时部署」推荐并发与交换机

| 项 | 建议（千兆接入） |
|----|------------------|
| 单机房并发部署目标 | **首批 40**，再分批滚动（`recommended_deploy_batch`） |
| 硬上限（Center） | `max_concurrent_deploy_targets` 默认 **80**（可配） |
| Edge 同步队列 | `max_pending_sync_per_edge` 默认 **16** |
| Edge 同步带宽 | `sync_bandwidth_bps` 可限速，避免挤占上课网 |
| 接入交换机 | 机房汇聚 **≥ 万兆上联**；接入口千兆全双工；关闭不必要的 storm control 误杀 |
| 广播域 | PXE/DHCP 仅在机房 VLAN；勿把 500 台塞进同一巨大二层 |

经验公式（粗算）：

```text
并发 ≈ min( Edge出口有效带宽 / 单机峰值拉流 ,
            接入交换机非阻塞转发能力 / 安全系数1.5 ,
            recommended_deploy_batch )
```

P2P 试点开启后，Edge 出口占比下降，同等带宽可提高并发；仍建议首班课用 40 验证再放大。

## 3. 新增机房

1. Center 创建校区/机房台账、登记客户端 MAC。  
2. `POST /api/v1/edges` 创建 Edge，保存 `node_token`。  
3. 部署 Edge 主机：写入 `deploy/config/edge.toml`（`center_url`、`node_token`、`cache_dir`、`cache_quota_bytes`、PXE 网段）。  
4. 启动 Edge，确认管理端「在线」且缓存水位为 `ok`。  
5. 将常用镜像「同步到边缘」，副本 `ready` 后再排部署任务。  

---

## 4. 更换 Edge / 轮换令牌

1. 新机器安装同版本 Edge 二进制与配置模板。  
2. **轮换令牌**：管理端边缘节点 →「轮换令牌」，或 `POST /api/v1/edges/{id}/rotate_token`。  
3. 把新 token 写入新 Edge 的 `edge.toml`，停旧启新。  
4. 重新同步镜像（或从备份恢复 `cache_dir` 后再校验）。  
5. 旧机下线；确认无残留 DHCP/PXE 双活冲突。

## 5. 备份与升级

### 备份

| 对象 | 路径/内容 | 频率建议 |
|------|-----------|----------|
| Center 数据库 | `database_url` 指向的 SQLite 文件（或后续 PG dump） | 每日 + 变更前 |
| Center 镜像库 | `images_dir` | 每日增量/周全量 |
| Edge 缓存 | `cache_dir`（可丢，可再同步；关键考前可快照） | 按磁盘策略 |
| 配置 | `deploy/config/*.toml`、令牌保险箱 | 随变更 |

恢复：停服务 → 还原 db + images_dir → 启动 Center → Edge 重注册/心跳 → 按需 resync。

### 升级

1. 读 `docs/modules/09-外部依赖与版本策略.md`，先升测试机房。  
2. 备份后滚动：先 Center，再各 Edge，最后 PE/agent。  
3. 跑对应 `deploy/scripts/stage*-accept.ps1` 冒烟。  
4. 生产窗口避开整班部署任务高峰。

## 6. 缓存水位

- Edge 配置 `cache_quota_bytes`、`cache_warn_pct`（默认 85）。  
- 心跳上报 `cache_used_bytes` / `cache_level`=`ok|warn|crit`。  
- `crit`/配额满：拒绝新同步，需「清空该镜像」或「整库清空」后重拉。
